# Diagram build scripts

The diagrams are generated by these scripts: English versions in `docs/`, Russian ones in `docs/ru/`. Edit a
script, not the `.excalidraw` file, and rebuild.

| File | What it does |
|---|---|
| `build_architecture.py` | `MINT_architecture.excalidraw` and `.excalidraw.md` (Obsidian) |
| `build_engineering.py` | `MINT_engineering.excalidraw` and `.excalidraw.md` |
| `en.py` | English text of every label (the key is the Russian label from the scripts) |
| `lang.py` | `--lang en`: swaps each label for its translation while the layout is computed |
| `render.py` | a PNG preview of a diagram (needs `matplotlib`) |
| `xl.py` | shared helpers for `build_engineering.py` |

```bash
cd tools/diagrams
python build_architecture.py ../../docs/ru/MINT_architecture
python build_architecture.py ../../docs/MINT_architecture --lang en
python build_engineering.py ../../docs/ru/MINT_engineering
python build_engineering.py ../../docs/MINT_engineering --lang en
python render.py ../../docs/MINT_architecture.excalidraw ../../docs/MINT_architecture_preview.png 0.5
python render.py ../../docs/MINT_engineering.excalidraw ../../docs/MINT_engineering_preview.png 0.35
python render.py ../../docs/ru/MINT_architecture.excalidraw ../../docs/ru/MINT_architecture_preview.png 0.5
python render.py ../../docs/ru/MINT_engineering.excalidraw ../../docs/ru/MINT_engineering_preview.png 0.35
```

The labels are written in Russian in the scripts. With `--lang en` every label is replaced by its translation in
the functions that wrap and place text, so box sizes are computed from the English text. A label without a
translation stops the build with a list of what is missing; `DIAGRAM_COLLECT=labels.json` writes all Russian
labels to a file.

`tests/test_diagrams.py` checks that `docs/` and `docs/ru/` match the scripts, that `en.py` has no translations
for labels that no longer exist, that every function, parameter and file named on the diagrams exists in the
code, and that the engineering diagram's parameter table (`SCENARIO_ROWS`) matches what `resolve_settings()`
computes for `SCENARIO_LIMITS`.
