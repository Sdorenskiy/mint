# Mint v21.4.1 — актуальные схемы и обязательная проверка перед релизами

Это **патч-релиз документации и контроля выпуска** поверх v21.4. Механизмы генерации документов и работы с требованиями не изменены.

- Обновлены **архитектурная и инженерная схемы** MINT: поток формирования Word из шаблона и оснований; автоматическое определение целевой системы и обязательное подтверждение человеком; извлечение и классификация требований по исполнителю; формирование документа; двусторонняя прослеживаемость; редактирование по выбранному основанию с подтверждением и отменой.
- Пересобраны редактируемые Excalidraw и Obsidian-версии на русском и английском и их PNG-превью.
- Исправлен номер версии, показываемый приложением: `21.4.1` соответствует GitHub-тегу `v21.4.1`.
- Добавлено обязательное правило: **перед каждым релизом** сверять и актуализировать обе схемы, их переводы и изображения. Тесты и workflow публикации проверяют версию и соответствие Excalidraw/PNG, блокируя выпуск при устаревших схемах.
- По-прежнему **не следует включать в Git** рабочие документы, сетевые настройки, ключи доступа, логи и реальные результаты экспертиз.

Качество формирования Word на реальных основаниях после PR #24–30 **пока не подтверждено отдельным контрольным прогоном**. Зелёные автоматические тесты с искусственными примерами этого не заменяют.

## Установка

Для новой установки используйте стандартный архив **Source code (zip)** GitHub Release и `install.sh` / `install.bat`. При обновлении существующей установки следуйте `update.sh` / `update.bat`; локальные настройки и база знаний не входят в исходники релиза.

# Mint v21.4.1 — updated diagrams and required release checks

A **documentation and release-gate patch** on top of v21.4. Application behavior is unchanged.

- Refreshed architecture and engineering diagrams describing Word drafting from template and selected sources, human-confirmed target context, actor-based requirement applicability, two-way evidence traceability and source-focused Word edit chat with approval and undo.
- Rebuilt Russian and English editable Excalidraw/Obsidian diagrams and PNG previews.
- Added a **mandatory pre-release rule**: verify and update both diagrams, translations and previews before every release. CI and release publishing verify tag and diagram-to-preview parity and refuse stale assets.
- Keep workplace documents, credentials, private configuration, local logs and real review output outside public Git.

Post-v21.4 real-document drafting quality still requires an independent user control run.
