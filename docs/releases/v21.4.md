# Mint v21.4 — Word drafting and evidence traceability

## Что нового

- Формирование черновика Word из шаблона или образца и выбранных документов-оснований; улучшена работа с длинными разделами, таблицами, титулом и оформлением.
- Определение целевой системы и границ документа с обязательным подтверждением пользователя; классификация требований по исполнителю и применимости. Неоднозначные требования остаются для ручной проверки.
- Двусторонняя прослеживаемость: от раздела Word к основанию и от извлечённого требования к разделам Word.
- Редактирование отдельных фрагментов Word через чат с просмотром различий, указанием источников, подтверждением и отменой изменений. Исправлены учёт устаревших связей и передача выбранного требования.
- Защита базы при несовместимой модели эмбеддингов, уточнение проверки содержания ответов и ссылок, улучшения аудита, обработки неполных ответов и повторного извлечения требований.
- Автоматические тесты с искусственными документами и имитацией ответов модели. Качество генерации на реальных документах после этих изменений ещё требует отдельного контрольного прогона.

## Установка и обновление

Скачайте «Source code (zip)» из этого GitHub Release. Для новой установки используйте `install.sh` или `install.bat`. Для обновления существующей установки остановите Mint и следуйте инструкции `update.sh` / `update.bat` из документации. Настройки, база знаний и рабочие документы не входят в архив релиза: они остаются локальными.

**Конфиденциальность:** не публикуйте реальные документы, файлы `.env`, локальную базу знаний, логи и результаты экспертного разбора в GitHub.

## What's new

- Draft Word documents from a template or completed example using selected source documents, with improved long-section, table, cover-page, and formatting handling.
- Detect and explicitly confirm target system and scope; classify source requirements by actor and applicability. Ambiguous items remain for human review.
- Trace extracted requirements in both directions: Word section to source and source requirement to Word.
- Revise selected Word fragments in a source-aware chat with diff, explicit acceptance, undo, and safely invalidated trace evidence.
- Improved embedding-profile compatibility safeguards, answer/content verification, audit reliability, incomplete-response handling, and extraction checkpoints.
- CI uses synthetic documents and mocked model responses. Real-document generation quality must still be evaluated separately.

## Installation and upgrade

Download the GitHub Release's “Source code (zip)”. For a fresh install, use `install.sh` or `install.bat`; for an existing installation, follow the documented `update.sh` / `update.bat` procedure. Runtime settings, knowledge-base content and working documents are not part of the source release.

**Privacy:** never commit real documents, `.env` files, local knowledge bases, logs, or expert-review data to GitHub.
