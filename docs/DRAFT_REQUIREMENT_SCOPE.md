# Применимость требований к целевой системе

После извлечения требований из всех выбранных документов-оснований Mint выполняет
**одну групповую классификацию на требование** с учётом подтверждённого контекста
будущего Word. Это отдельный этап от фактической проверки цитат.

- `target` — прямое обязательство целевой системы, кандидат для Word;
- `shared` — общее требование, применимое также к целевой системе, кандидат;
- `interaction` — обязательство внешнего участника, которое допускается
  использовать **только как контекст внешнего обмена**, не как обязательство целевой системы;
- `other` — требование другой платформы вне задачи, не передаётся для формирования;
- `uncertain` — применимость не установлена: НЕ добавляется в формирование
  автоматически, сохраняется для пользователя в отчёте.

Классификация возвращает `actor` (субъект обязанности) и `reason`
(объяснение). Если LLM не ответила/пропустила ID, категория остаётся
`uncertain`; пользователь получает одно агрегированное замечание, а не
сотни комментариев Word. Исходные проверенные цитаты не удаляются — всё
остаётся доступно для последующего анализа полноты и ручного исправления.

Чат для доработки Word продолжает опираться на выбранные пользователем
основания. Классификация помогает не допускать чужих обязанностей при первой
генерации, но сама по себе не доказывает правильность текста. Следующий PR
отобразит классификацию и фактический перенос каждого требования.

Тестовый набор проверяет не только текстовое совпадение, но и различие
обязанностей платформ А/Б/В и отказ от уверенного переноса при неизвестном
субъекте.
