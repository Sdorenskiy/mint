# Проверка качества Mint на реальных документах (PR #22)

**Рабочие документы никуда не загружаются через GitHub.** Проверка делается в установленной локально версии Mint, результат пользователь размечает сам.

## Аудит

Используйте существующую функцию «Экспертный разбор» сохранённого аудита. Отметьте ложные замечания, допустимые замечания и вручную добавьте те, которые Mint пропустил. Экспорт без текстов доступен в существующем разборе.

## Генерация Word

1. Сформируйте черновик на выбранном шаблоне/образце и документах-основаниях.
2. Скачайте документ, проверьте его содержание и раздел 7.1 **в Word**.
3. Откройте «Проверка качества сформированного документа (локально)» и нажмите «Сохранить черновик для экспертного разбора». Только по этому действию Mint сохраняет локальный снимок списка исходных требований и созданных фрагментов.
4. По очереди отметьте извлечённые требования: **перенесено правильно / пропущено / искажено / неприменимо**. Список постраничный — по 15 требований. Впишите отдельно каждое существенное требование, которое Mint **вообще не извлёк**, и утверждения итогового документа, для которых нет основания.
5. Сохраните оценки. Разбор можно открыть после перезапуска Mint. При необходимости выгрузите **обезличенную сводку**; тексты и имена файлов в неё не включаются.

Данные находятся в `LOG_DIR/draft_reviews/`. Там могут быть конфиденциальные цитаты и сформированные абзацы: **не копируйте эту папку в GitHub, не публикуйте и ограничьте доступ к ней**. Сохранённые исходные Word-документы здесь не дублируются.

При повторной генерации одинакового комплекта можно сравнить две экспертные оценки (из разных версий Mint/промптов). Сравнение предварительное: разное число извлечённых и размеченных требований способно исказить проценты. Доля «корректно перенесённых среди оценённых применимых» **не означает Recall по всем требованиям основания**: необходимо явно записывать и требования, не найденные системой.

## Рекомендуемый протокол

Для начального замера используйте 2–3 типичных комплекта: один сложный шаблон с разделом 7.1, один с таблицами, один с противоречивыми основаниями. Сохраните модель, версию Mint, состав вики, промпты и настройки. Сначала проверьте текущую версию, затем ту же задачу после оптимизации. Не меняйте состав исходных документов между замерами.

Без реального независимого экспертного разбора CI и синтетический golden-набор **не могут** подтвердить увеличение качества.
