# Из требования основания — в чат по Word

После формирования Word откройте «Требования и их отражение в Word».
Найдите исходный пункт по разделу документа или по файлу-основанию.
Выберите в интерфейсе, **какой именно фрагмент Word** хотите доработать.
В карточке требования нажмите «Доработать через чат».

Mint откроет чат редактирования уже на выбранном фрагменте и поставит
в запрос цитату, название основания и его раздел. Пользователь вправе
изменить запрос, нажать «Предложить изменение», проверить текстовый diff,
принять/отклонить и скачать Word. Автоматического применения нет.

Если пункт относится к другой платформе либо применимость неясна,
начальная формулировка запроса предлагает **сначала проверить исполнителя**,
а не автоматически вставлять чужую обязанность в целевой документ.

После подтверждения изменения прошлые связи в затронутом разделе
отмечаются как требующие повторного просмотра. Текстовое совпадение,
установленное в момент исходной генерации, не считается доказательством
для изменённой версии. Состояние отмены правки восстанавливает
предыдущий статус. Дополнительного LLM-вызова для интерфейса нет.

Данные хранятся в обычной памяти сеанса Streamlit. Для генерации новой
редакции используется существующий шлюз Mint и общий механизм
выбора источников с фильтром ролей PR27. Исходные оригиналы не меняются.

Тесты проверяют смену статусов после правок, безопасное составление
запроса на основании цитаты, контекст целевой системы и то, что
обязанности другой платформы не переходят в список оснований прямой
правки целевой системы.
