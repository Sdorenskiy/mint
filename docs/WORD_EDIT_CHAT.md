# Чат по сформированному Word: первая рабочая версия

После сборки черновика откройте во вкладке **«Составление документа»** блок **«Чат по сформированному документу»**. Это продолжение работы с результатом, а не новый независимый генератор.

1. Выберите редактируемый **раздел**, отдельный **абзац** или **ячейку таблицы**. Раздел предлагается целиком только тогда, когда его обычные абзацы можно безопасно заменить без затрагивания таблиц или защищённых Word-элементов. В других случаях выбирайте отдельные фрагменты.
2. Напишите, что изменить: например, «добавь порядок повторной доставки по основаниям», «сделай формулировку конкретнее», «поясни условия отказа».
3. Модель использует **текущий выбранный текст**, несколько предыдущих реплик и требования, уже извлечённые при первоначальной генерации. Она предлагает **полную новую редакцию только выбранного фрагмента**, а не редактирует файл сразу.
4. Проверьте различия «было → станет», объяснение, цитаты оснований и предупреждения о недостаточной подтверждённости. У модели могут быть ошибки; оценка цитат не доказывает смысловую полноту.
5. Нажмите **«Принять правку»** или **«Отклонить правку»**. Можно несколько раз уточнять предложение до принятия. После принятия обычная кнопка скачивания выдаёт уже изменённый DOCX. **«Отменить последнюю правку»** восстанавливает предыдущую версию.

## Границы и защита данных

- Чат доступен для **сформированного в Mint** черновика. Произвольный загруженный DOCX и массовые изменения по всему документу — следующий отдельный этап, не обещаем их в этой версии.
- Внешние LLM-вызовы выполняются по уже настроенному шлюзу Mint. Данные выбранного фрагмента и найденных оснований передаются **этому шлюзу** так же, как при исходной генерации. Никакой дополнительной внешней службе чат документы не передаёт.
- Данные сеанса (исправленная копия, предложения, история) находятся в памяти Streamlit, **не сохраняются локально между перезапусками**. Скачайте результат перед завершением сеанса. Хранится до десяти обратимых состояний.
- Подтверждение человека обязательно. Перед применением проверяются SHA-256 редакции всего DOCX и неизменность выбранного текстового фрагмента. Устаревший ответ не применяется.
- Поля Word, ссылки и гиперссылки, закладки, объединённые ячейки, заголовки и другие защищённые элементы не редактируются автоматически. Списки с явной Word-нумерацией нельзя переписывать как целый раздел.
- **Исходный объект результата генерации не перезаписывается.** Экспертная оценка качества PR #22 по-прежнему оценивает первоначальный результат, а не правки, одобренные в чате.
- При отсутствии цитат или неподтверждённых числах показывается предупреждение. Пользователь может явно принять собственную редакторскую инструкцию, но она не считается доказанной основанием.
- После добавления новых абзацев список целей пересчитывается. Старые диалоги очищаются, чтобы не привязать их ошибочно к другим местам документа.

## Тесты

`python tests/test_document_edit.py`: локальные фиктивные DOCX, выбор раздела/абзаца/ячейки, предварительное предложение без изменений файла, подсказки по источникам, принятие, запрет устаревшей правки, сохранение заголовков/таблиц/ссылок и защита Word. Сквозные тесты генератора PR #24 также выполняются.

**Критерий выпуска:** на реальном документе можно без повторной генерации выбрать нужное место, уточнить его в диалоге, увидеть различия и получить редактируемый Word с сохранённой структурой. Семантическое качество предложений необходимо проверить вручную.
